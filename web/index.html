open-transit-wall

Flash the ESP32 firmware and point it at your WiFi + transit proxy — straight from the browser. Nothing is uploaded; the device talks to your computer over USB serial.

This browser can't talk to USB serial. Use desktop Chrome or Edge (or Chrome on Android), and open this page over https:// or localhost.

Before you start

    
    
      
  • Connect the ESP32 over USB. Use a data cable, not a charge-only one.
    • 
      
  • Some clone boards need the WCH CH34x driver — see the project README.
    • 
      
  • Flashing erases the device, including any existing settings.
    • 
      
  • If auto-reset fails, hold BOOT, tap EN, release BOOT,
        then click the button.
    • 
      
  • After it reboots the status pixel at the top-left of the wall turns
        green when the proxy is reachable.
